AnchorHub — Settings

Adapters

Enable an adapter to let AnchorHub talk to it. While enabled, the corresponding section in the popup, badges, and in-page markers are shown.

Microsoft Graph sign-in

AnchorHub ships with a pre-registered Microsoft application — just sign in. The first sign-in prompts Microsoft to authorise read-only OneNote access (Notes.Read) for the AnchorHub app against your account.

Advanced — use your own Azure AD app

Override the built-in client ID with one from a tenant you control. Setup steps live in docs/graph-setup.md. Leave the fields empty to use the built-in app.

Use common for multi-tenant + personal accounts, or a tenant GUID for single-tenant apps.

Register http://localhost under Authentication → Mobile and desktop applications. AnchorHub's daemon picks a fresh loopback port on each sign-in — Azure accepts any port and any path under that host (RFC 8252).
